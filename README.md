### 🔬 What I work on

I build numerical simulations and models spanning **soft matter / biophysics** (vertex models of tissues, active Brownian particles, organoid growth) and **statistical physics** (Ising models, Monte Carlo methods, reaction–diffusion and KPZ-type PDEs). Most of my code is in Fortran and MATLAB for solvers, with Python for analysis, visualization, and glue.
